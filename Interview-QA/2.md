**What is the difference between an alert, a detection, and an incident?**

- An alert is a raw signal that something potentially suspicious occurred.
- A detection is an alert that has been analyzed and classified as suspicious or malicious based on logic, context, or analytics.
- An incident is a collection of one or more related detections that together represent a confirmed or likely security event requiring response.

An alert is the raw signal-a notification from a security tool that a specific condition, like a high volume of traffic, has been met. A detection occurs when we apply context or intelligence to those signals to identify probable malicious behavior; it is the conclusion that the activity is not just noise but represents a threat actor's tactics.

An incident is the final stage where we confirm that an adverse network event has occurred or is imminent, constituting a violation of our security policy. While we might receive thousands of alerts daily, only a small fraction is validated as detections, and fewer still are declared as incidents that require the activation of an Incident Response Plan.  
<br/>Scenario: Multiple failed logins attempt on a critical server.

1\. Alert: The SIEM triggers a notification because a threshold of five failed logins in one minute was exceeded.

2\. Detection: An analyst reviews the logs and sees the attempts are targeting the 'Administrator' account from a known malicious IP; this identifies an Initial Access attempt.

3\. Incident: The analyst finds one successful login followed by the creation of a new user account; an incident is declared as persistence is now achieved.

**In CrowdStrike Falcon, these concepts are explicitly separated:**

**Alert (Event / Signal)**

- Raw telemetry from the Falcon sensor or integrated sources  
    Examples:
  - Process execution
  - DLL load
  - Network connection
- Seen in Event Search / Host Timeline
- Not all alerts require action

**Detection**

- A Falcon analytic decision that suspicious behavior occurred

Generated by:
    - IOAs
    - Behavioral ML
    - Cloud analytics
- Has
  - Severity
  - Tactic/Technique
  - Process tree context

Example: Suspicious DLL Load via Unsigned DLL detection

**Incident**

- Falcon correlates multiple detections into a single incident
- Represents coordinated adversary activity
- What SOC Leads and IR teams actually work

In Falcon, incidents drive response, not individual alerts.
